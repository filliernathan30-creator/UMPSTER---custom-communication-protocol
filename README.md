# UMPSTR---custom-communication-protocol
this is a *currently unfinished* library that allows the user to create a communication protocol between two arduinos using any amount of pins, to send a message of any preknown length, as fast as the arduinos will allow

UMPSTR, stands for Universal Multi-Pin Synchronous Transmitting and Receiving

the protocol uses two clock pins, one coming from each MCU, and at least one data transfer pin. all pins must be digital pins.
